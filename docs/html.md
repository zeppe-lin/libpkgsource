# HTML documentation

## Purpose

The HTML tree is a versioned publication artifact generated by this owner
repository. Pandoc renders canonical Markdown; Doxygen renders both public C++
APIs.

HTML generation is disabled by default. Ordinary library builds do not depend
on Pandoc or Doxygen.

## Output and installation

With `-Dhtml_docs=enabled`, the build produces:

```text
build/docs/html/libpkgsource/3.0.0/
├── index.html
├── architecture.html
├── abi.html
├── manual/
├── protocols/
├── history/
├── api/
├── assets/
└── legal/
```

Installation places the same opaque artifact under:

```text
${prefix}/share/htmldocs/libpkgsource/3.0.0/
```

The website may publish this directory directly. It must not reinterpret the
headers or regenerate owner documentation.

## Validation

Generation fails on missing source documents, Pandoc warnings, Doxygen
warnings, broken local links, Markdown links escaping into HTML, absolute source
or build paths, incomplete legal or API trees, and unsupported Pandoc major
versions.
